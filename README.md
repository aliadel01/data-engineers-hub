Welcome to **Data Engineers Hub** — an open, high-signal technical community designed for Data Engineers to exchange knowledge, analyze architecture designs, and master production-grade technologies.


## Community Architecture

Our interaction happens on **WhatsApp Communities**, supported by this GitHub repository for persistent, searchable knowledge.

* **📢 Announcements:** Official updates, job opportunities, weekly technical digests, and scheduled community events (Admins Only).
* **💬 Community Chat:** The primary workspace for daily technical discussions, system architecture debates, resource sharing, and troubleshooting.

## Community Rules

To maintain a focused environment for technical growth, all members must adhere to these operational principles:

1. **Strictly Domain-Focused:** Discussions are restricted to Data Engineering and Software Domain. Off-topic discussions are prohibited.
2. **No Promotions or Spam:** Promotional content, unauthorized ads, and spam are strictly forbidden and will result in an immediate ban.
3. **Professional Conduct:** Respectful communication is required at all times. Harassment, insults, or abusive language will not be tolerated.

## Repository Structure

* **`resources.md`**: A curated index of learning roadmaps, courses, foundational textbooks, and engineering case studies across core data engineering domains.
* **`docs/`**: Community-contributed guides, system design notes, and interview preparation archives.



## Contribution Guidelines

We welcome contributions to our shared knowledge base!
1. Fork the repository.
2. Create a new feature branch (`git checkout -b add-resource-name`).
3. Commit your updates in accordance with the existing Markdown format.
4. Submit a **Pull Request** with a concise description of your additions.
